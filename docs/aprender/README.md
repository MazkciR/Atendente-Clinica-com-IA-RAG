Este guia é para quem **nunca montou um chatbot** (júnior em tecnologia) e também para quem é **de fora da área** e só quer entender como funciona. Cada termo difícil é explicado quando aparece e reunido no [Glossário](02-glossario.md).

## O que você vai precisar para rodar

- Um computador com Windows, Mac ou Linux.
- **Python** e **Git** instalados (o passo a passo mostra como conferir).
- Uma **chave gratuita** da API do Gemini, que você mesmo gera em https://aistudio.google.com/apikey.
- Cerca de 30 minutos.

Nada neste projeto usa dados reais de pacientes.
